## Nazariya

### `for` — sanashni Python o'zi qiladi

`while` da hisoblagichni siz boshqarasiz: yaratasiz, oshirasiz, kuzatasiz. `for` esa
tayyor ketma-ketlik bo'ylab o'zi yuradi — adashish joyi qolmaydi.

<Atama soz="iteratsiya" eng="iteration">
	Sikl bir marta aylanishi. `for b in baholar` yozilganda Python ro'yxatning har
	elementi uchun bitta iteratsiya bajaradi.
</Atama>

<Kod
	kod={`baholar = [4, 5, 3, 5, 2]
for b in baholar:
    print(b)`}
	sarlavha="royxat.py"
/>

### `range` — sonlar ketma-ketligi

`range(5)` → 0, 1, 2, 3, 4 (oxirgisi kirmaydi). `range(1, 6)` → 1..5.
`range(0, 10, 2)` → 0, 2, 4, 6, 8. Uchinchi son — qadam.

<Kod
	kod={`for i in range(1, 6):
    print(i, "x 7 =", i * 7)`}
	sarlavha="jadval.py"
/>

### To'rt akkumulyator naqshi

Boshlang'ich masalalarning katta qismi to'rt naqshdan biriga tushadi. Hammasi bir
xil skelet ustiga qurilgan: sikldan oldin **boshlang'ich qiymat**, sikl ichida
**yangilash**, sikldan keyin **natija**.

<Kod
	kod={`jami = 0                      # 1. Yig'indi
for b in baholar:
    jami = jami + b
soni = 0                      # 2. Sanoq
for b in baholar:
    if b == 5:
        soni = soni + 1
eng = baholar[0]              # 3. Maksimum
for b in baholar:
    if b > eng:
        eng = b
yaxshi = []                   # 4. Filtr
for b in baholar:
    if b >= 4:
        yaxshi.append(b)`}
	sarlavha="naqshlar.py"
/>

<Muhim turi="gap">
	Bu to'rt naqsh — yig'indi, sanoq, maksimum, filtr — birgalikda boshlang'ich
	masalalarning 80% ini yechadi. Ularni yodlash emas, **tanib olish** kerak:
	masalani ko'rganda «bu qaysi naqsh?» deb so'rang.
</Muhim>

Maksimum naqshida boshlang'ich qiymat 0 emas, `baholar[0]` bo'lgani muhim: ro'yxatdagi
barcha sonlar manfiy bo'lsa, 0 dan boshlagan kod xato javob beradi.

## O'zingizni sinang

<Sinov raqam={1} savol="range(1, 6) qanday sonlarni beradi?">
	1, 2, 3, 4, 5. Boshlanishi kiradi, oxiri kirmaydi.
</Sinov>

<Sinov raqam={2} savol="Qachon for, qachon while qulayroq?">
	Ketma-ketlik oldindan ma'lum bo'lsa (ro'yxat, <code>range</code>) —
	<code>for</code>. Necha marta aylanishi noma'lum bo'lsa (to'g'ri parolgacha) —
	<code>while</code>.
</Sinov>

<Sinov raqam={3} savol="To'rt akkumulyator naqshini nomlab bering va har biri qanday savolga javob beradi.">
	Yig'indi (jami qancha), sanoq (nechta shunday element bor), maksimum (eng kattasi
	qaysi), filtr (shartga mos elementlar ro'yxati).
</Sinov>

<Sinov raqam={4} savol="Maksimum naqshida nega eng = 0 emas, eng = royxat[0] deb boshlanadi?">
	Ro'yxatdagi barcha sonlar manfiy bo'lsa, <code>0</code> dan boshlangan kod
	maksimum sifatida 0 ni qaytaradi — bu esa ro'yxatda yo'q son.
</Sinov>

<Sinov raqam={5} savol="30 o'quvchi bahosining o'rtachasini topish uchun qaysi naqsh kerak?">
	Yig'indi naqshi, keyin natijani element soniga bo'lish:
	<code>jami / len(baholar)</code>.
</Sinov>
