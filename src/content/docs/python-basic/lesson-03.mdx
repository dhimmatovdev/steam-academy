## Nazariya

### To'rt asosiy tur

Python har qiymatning turini biladi va turga qarab amallarni boshqacha bajaradi.
Boshlanish uchun to'rttasi yetadi: `int` (butun son), `float` (kasr son),
`str` (satr, ya'ni matn) va `bool` (faqat `True` yoki `False`).

<Atama soz="tur" eng="type">
	Qiymatning qanday ma'lumot ekani. Tur amallarning ma'nosini o'zgartiradi:
	`3 + 4` qo'shish, `"3" + "4"` esa ulash — natija `"34"`.
</Atama>

Shubha bo'lsa `type()` dan so'rang: `type(5)` → `<class 'int'>`,
`type("5")` → `<class 'str'>`. Bu ikkisi ekranda bir xil ko'rinadi, lekin butunlay
boshqa narsa.

### Uch xil bo'lish

`/` har doim kasr son qaytaradi, hatto teng bo'linsa ham: `10 / 2` → `5.0`.
`//` butun bo'linmani beradi (kasr qismini tashlaydi): `10 // 3` → `3`.
`%` qoldiqni beradi: `10 % 3` → `1`.

<Kod
	kod={`jami = 100000
odam = 7
print(jami // odam)   # 14285 — har kishiga
print(jami % odam)    # 5     — ortgan pul
print(jami / odam)    # 14285.714285714286`}
	sarlavha="bolish.py"

### Kasr sonlar aldaydi

`0.1 + 0.2` ni Python `0.30000000000000004` deb hisoblaydi. Bu xato emas: 0.1 sonini
ikkilik sanoqda **aniq** yozib bo'lmaydi, xuddi 1/3 ni o'nlikda aniq yozib
bo'lmagani kabi. Sababi [CF 3-darsda](/computer-fundamentals/lesson-03/) batafsil.

<Muhim turi="ogoh">
	Kasr sonlarni `==` bilan solishtirmang. `0.1 + 0.2 == 0.3` natijasi `False`.
	To'g'ri yo'l: `abs(a - b) < 0.0001` — ya'ni "farq juda kichikmi?"
</Muhim>

### Turlarni aylantirish

`int("25")` satrni songa, `str(25)` sonni satrga, `float("3.5")` satrni kasr songa
aylantiradi. Bu keyingi darsda hayotiy zarur bo'ladi: `input()` har doim satr qaytaradi.

## O'zingizni sinang

<Sinov raqam={1} savol="type(5) va type('5') natijalari nima va farqi nimada?">
	<code>&lt;class 'int'&gt;</code> va <code>&lt;class 'str'&gt;</code>. Birinchisi son —
	hisoblashda ishlatiladi; ikkinchisi matn — faqat ulanadi va takrorlanadi.
</Sinov>

<Sinov raqam={2} savol="100 000 so'mni 7 kishiga bo'lishda // va % nimani beradi?">
	<code>100000 // 7</code> = 14285 — har kishiga tegadigan summa.
	<code>100000 % 7</code> = 5 — bo'linmay ortgan so'm.
</Sinov>

<Sinov raqam={3} savol="2 + 3 * 4 ** 2 ifodasining natijasi nima?">
	50. Tartib: daraja (<code>4**2</code>=16), keyin ko'paytirish (<code>3*16</code>=48),
	oxirida qo'shish (<code>2+48</code>=50).
</Sinov>

<Sinov raqam={4} savol="Nega 0.1 + 0.2 == 0.3 natijasi False?">
	0.1 va 0.2 ikkilik sanoqda aniq ifodalanmaydi, shuning uchun yig'indi
	<code>0.30000000000000004</code> bo'lib chiqadi. Kasr sonlarni tenglikka emas,
	farqning kichikligiga tekshirish kerak.
</Sinov>

<Sinov raqam={5} savol="'10' satrini songa aylantirib 5 qo'shish uchun qanday yozasiz?">
	<code>int("10") + 5</code> — natija 15. <code>"10" + str(5)</code> yozilsa natija
	<code>"105"</code> satri bo'ladi.
</Sinov>
