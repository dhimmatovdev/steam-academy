- siklning uch qismini (holat, shart, o'zgarish) ajratib ko'rsatasiz
- cheksiz sikl sababini topasiz va tuzatasiz
</Maqsad>

## Nazariya

### Sikl uch qismdan iborat

Har ishlaydigan `while` siklida uchta narsa bo'ladi: sikl boshlanishidan oldingi
**boshlang'ich holat**, har aylanishda tekshirilib turadigan **shart** va sikl ichidagi
**o'zgarish**. O'zgarish shartga ta'sir qilmasa, sikl to'xtamaydi.

<Atama soz="sikl" eng="loop">
	Kodning bir bo'lagini shart bajarilib turgan vaqtda qayta-qayta bajarish.
	`while` — «shu shart rost ekan, davom et» degani.
</Atama>

<Kod
	kod={`jami = 0        # 1. boshlang'ich holat
i = 1
while i <= 5:   # 2. shart
    jami = jami + i
    i = i + 1   # 3. o'zgarish
print(jami)     # 15`}
	sarlavha="yigindi.py"
	qatorlar={[1, 3, 5]}
/>

### Cheksiz sikl

`i = i + 1` qatorini olib tashlasangiz, `i` doim 1 bo'lib qoladi, shart doim rost
bo'ladi va programma to'xtamaydi. Terminalda `Ctrl+C` bosib to'xtatiladi.

<Muhim turi="ogoh">
	Cheksiz sikl — xato emas, **belgi**: siz o'zgarishni yozishni unutgansiz yoki
	o'zgarish shartga ta'sir qilmayapti. `while` yozganda birinchi savol: «bu shart
	qachon yolg'on bo'ladi?»
</Muhim>

### `break` va shartli chiqish

Ba'zan chiqish sharti sikl o'rtasida ma'lum bo'ladi — o'shanda `break` ishlatiladi.
U siklni darhol to'xtatadi va shartni ham tekshirmaydi.

<Kod
	kod={`while True:
    parol = input("Parol: ")
    if parol == "steam":
        print("Kirdingiz")
        break
    print("Xato, yana urinib ko'ring")`}
	sarlavha="parol.py"
	qatorlar={[5]}
/>

`while True` — ataylab cheksiz sikl, chiqish esa `break` orqali. Bu naqsh parol,
menyu va o'yin siklida ko'p uchraydi.

## Bashorat qiling

<KodBashorat
	kod={`n = 3
while n > 0:
    print(n)
    n = n - 1
print("Boshladik!")`}
	javob={`3
2
1
Boshladik!`}
	izoh="Har aylanishda n chiqariladi va bittaga kamayadi. n = 0 bo'lganda shart yolg'on bo'ladi va sikldan chiqiladi — 0 chiqarilmaydi."
/>

<KodBashorat

jami = 0
while i < 4:

/>

## Sinab ko'r

Uch programma bor. Uchinchisida `i = i + 1` qatori ataylab izohga olingan — cheksiz
sikl qanday ko'rinishini xavfsiz kuzatishingiz mumkin.

</Xato>

## O'zingizni sinang

<Sinov raqam={1} savol="Siklning uch qismi qaysilar?">
	Boshlang'ich holat (sikldan oldin), shart (<code>while</code> yonida) va o'zgarish
	(sikl ichida). O'zgarish shartga ta'sir qilmasa, sikl cheksiz bo'ladi.
</Sinov>

<Sinov raqam={2} savol="n = 3 bo'lsa, while n > 0 sikli nechta son chiqaradi va nechtasi?">
	Uchta: 3, 2, 1. <code>n = 0</code> bo'lganda shart yolg'on bo'ladi, shuning uchun
	0 chiqmaydi.
</Sinov>

<Sinov raqam={3} savol="Cheksiz sikl paydo bo'lganda uni qanday to'xtatasiz va sababini qanday topasiz?">
	Terminalda <code>Ctrl+C</code>. Sababni topish uchun savol berish kerak: «shart
	qachon yolg'on bo'ladi?» — agar javob yo'q bo'lsa, o'zgarish yozilmagan yoki
	shartga ta'sir qilmayapti.
</Sinov>

<Sinov raqam={4} savol="while True: qachon ishlatiladi va undan qanday chiqiladi?">
	Chiqish sharti sikl o'rtasida ma'lum bo'lganda (parol so'rash, menyu).
	Chiqish <code>break</code> orqali bo'ladi.
</Sinov>

<Sinov raqam={5} savol="Sikl ichidagi qatorning otstupi bo'lmasa nima bo'ladi?">
	U qator sikldan tashqarida qoladi va sikl tugagandan keyin bajariladi. Agar bu
	qator o'zgarish bo'lsa — sikl cheksiz bo'ladi, lekin Python xato bermaydi.
</Sinov>
